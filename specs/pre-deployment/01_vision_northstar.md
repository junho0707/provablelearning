# North Star Doc 

    1. program model    
        > subjects: 
            phase 1: digital sat reading & writing, sat math, combined
                >> students may enroll in rw | math | rw & math
                >> group sizes: 1:1 (limited), small (2-4), medium (5-9), large (10-30)
                >> pricing differs by group size
                    1:1 : $800 -> 12 Hours of Instruction -> $66.67 / Hour 
                    Small : $100 
                    Medium : $50 
                    Large : $20 
                >> curriculum pacing identical;
                    smaller groups receive more personalized feedback 
                >> large groups use lecture-style instruction 
                    with interactive submission + feedback 

    2. academic structure 
        > structured 4-week module 
        > 8 sessions per month (2x week)
        > multiple time slots available per week 
        > makeups:
            1:1:
                Allowed & Reschedule Based on Tutor's Availability
                - If not rescheduled by end of week (Sunday), credit auto-issued

            Small Group:
                - Allowed via alternate session same week
                  IF notified 24 Hours Before
                - If not made up by end of week (Sunday), credit auto-issued

            Medium Group:
                - Allowed via alternate session same week
                - If not made up by end of week (Sunday), credit auto-issued

            Large Group:
                - Allowed via alternate session same week
                - No credit issued
 
        > students can re-enroll in same module (but max 3)

    3. payment system 
        > one-time payment per 4-week module 
        > embedded stripe checkout 
        > automatic tax handling 
        > refunds: case-by-case (parent schedules consultation via /book)

    4. roles & permissions
        > parents: pay, receive pdf reports, email + sms updates, schedule meetings 
        > students: attend class, submit homework, access recordings/materials, ask questions during oh 
        > students may enroll independently 
        > parents do not attend live sessions 
    
    5. communication system 
        > google workspace backbone
        > google classroom 'ask your questions' Forum
        > parent contacted via email + dedicated sms line 

    5. weekly operation flow
        > before class : homework & class reminder + materials uploaded  
        > during class : google meet session recorded automatically 
        > after class : slides uploaded, homework assigned via google forms 
        > feedback returned 
        > weekly performance logged

    6. performance tracking 
        > attendance, hw completion, weekly performance 
        > skill tags mapped to official sat domains 
        > monthly clean pdf summary emailed to parents 
        > simplified improvement overview 

    7. folder architecture 
        > cohorts folder per module 
        > students folder per student 
        > recordings folder per module 
        > homework stored only in student folder 

    8. capacity strategy
        > 1:1 capped 
        > group-focused scalability 
        > standardized curriculum 
        > designed to scale to ~ 50 students 

    9. academic standards 
        > homework required 
        > formal academic policy document exists 
        > professional, structured academic tone
